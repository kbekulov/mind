# Project instructions

- Repository: https://github.com/kbekulov/mind
- Website: https://mind.bekulov.com
- Hosting: GitHub Pages. Preserve the root `CNAME` pointing to `mind.bekulov.com`.
- Every time you make changes to this project, verify them as appropriate, commit all relevant task changes, and push to GitHub before finishing. Do this automatically unless the user explicitly requests otherwise. Exclude unrelated changes and clearly report any commit or push failure.
- If the user asks to improve, translate, or otherwise manipulate text or an image, return only the manipulated content, without introductory or closing explanations.
- When writing Suno prompts, return only a lyrics prompt and a style prompt, each in its own code block. In the lyrics prompt, all text outside square brackets is vocalized; text inside square brackets is an instruction or description. Keep lyrics prompts within 5,000 characters and style prompts within 1,000 characters.
